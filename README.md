# AI-Driven Social Engineering and Deepfake Defense Platform

A defense-in-depth cybersecurity platform engineered to detect social engineering attacks, SMS phishing (smishing), fraudulent lures, and synthetic media deception.

Developed by **Team Sentinels** (Vivek Sharma, Hitesh Brahmi, Akhil Kotwal)

---

## 🌟 Key Features

1. **Hybrid Threat Detection Engine:**
   - **Machine Learning Layer:** Multinomial Naive Bayes paired with TF-IDF unigram & bigram vectorization (trained on the verified UCI SMS Spam Collection dataset).
   - **Rule-Based Heuristic Layer:** Scans for psychological attack vectors including artificial urgency, financial/prize bait, credential harvesting, and deceptive/shortened URLs.
   - **Explainable Output:** Delivers a clear 0–100 risk score, a color-coded status (Safe, Suspicious, Dangerous), and human-readable justification reasons.
2. **Interactive Streamlit Web Dashboard:**
   - **Home:** Executive summary and high-level platform introduction.
   - **Live Demo:** Real-time text analysis with rotating realistic test templates (Fake Bank SMS, Prize Scam, Normal Message, and Random sample generator).
   - **The Problem:** Detailed breakdown of social engineering vectors (phishing, voice cloning, video deepfakes) and a case study of the 2024 Arup Hong Kong deepfake CFO incident ($25M transfer).
   - **How It Works:** Streamlined architecture diagram and core pipeline breakdown.
   - **Results:** Clean summary of real evaluation metrics (98.4% accuracy, 97.8% precision, 89.9% recall) and operational limitations.
   - **Deepfake Detection:** Clearly labeled as **"In Progress / Unavailable in v1.0"** with an overview of planned v2.0 capabilities.
   - **About:** Team members and project specifications.
3. **100% Offline & Privacy-First:**
   - Zero cloud API dependencies. User text is never transmitted over the internet or logged to third parties.

## 🚀 Exact Run Steps for Windows

### 1. Open PowerShell or Command Prompt
Open your terminal and navigate to the project directory:
```powershell
cd "C:\Users\Vivek Sharma\OneDrive\Desktop\mdc"
```

### 2. Set Up Virtual Environment (Recommended)
Create and activate a virtual environment to isolate project packages:
```powershell
# Create virtual environment
python -m venv .venv

# Activate in PowerShell
.\.venv\Scripts\Activate.ps1

# (Or in Command Prompt: .\.venv\Scripts\activate.bat)
```

### 3. Install Dependencies
Install all required libraries from `requirements.txt`:
```powershell
pip install -r requirements.txt
```

### 4. Train the Model & Generate Real Metrics
Run the training pipeline. This trains the TF-IDF vectorizer and Naive Bayes classifier on `data/SMSSpamCollection`, evaluates performance on a 20% holdout test set, and saves the trained artifacts into `models/`:
```powershell
python src/train.py
```

### 5. Launch the Streamlit Web Application
Run the local Streamlit dashboard:
```powershell
streamlit run app.py
```
Streamlit will automatically launch in your default browser at:
`http://localhost:8501`

### 6. Run the Automated Test Suite (Optional)
To verify detection outputs against 3 scam and 3 normal messages:
```powershell
python tests/test_detection.py
```

## 📊 Real Evaluation Performance (Holdout Test Split: N = 1,115)

The following metrics are **genuine outputs** recorded from training on the 5,572-message SMS dataset:

| Metric | Real Score | Notes |
| :--- | :---: | :--- |
| **Accuracy** | **98.39%** | Overall correct classifications across all test samples |
| **Precision (Spam)** | **97.81%** | 97.8% of messages flagged as scams are truly scams |
| **Recall (Spam)** | **89.93%** | 134 out of 149 real scam messages in test split detected |
| **F1-Score** | **93.71%** | Harmonic balance between precision and recall |

### Confusion Matrix

| Actual \ Predicted | Predicted Safe (Ham) | Predicted Scam (Spam) |
| :--- | :---: | :---: |
| **Actual Safe (Ham)** | **963** *(True Negatives)* | **3** *(False Positives)* |
| **Actual Scam (Spam)** | **15** *(False Negatives)* | **134** *(True Positives)* |

- **False Positive Rate:** Only 3 out of 966 legitimate messages were mistakenly flagged ($0.3\%$).
- **Defense-in-Depth Advantage:** The rule-based heuristic layer compensates for statistical false negatives on modern delivery/cryptocurrency scams that were rare in older datasets.
